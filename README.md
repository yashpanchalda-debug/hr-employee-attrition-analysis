# HR Employee Attrition Analysis

A beginner-to-intermediate data analysis project exploring patterns behind employee attrition using SQL, Python, and Excel. This project is designed to demonstrate practical data analysis skills using a real-world HR dataset.

## Project Overview

Employee attrition (turnover) is a costly challenge for organizations. This project analyzes the [IBM HR Analytics Employee Attrition dataset](https://www.kaggle.com/datasets/pavansubhasht/ibm-hr-analytics-attrition-dataset) to identify which factors most strongly predict whether an employee will leave.

## Skills Demonstrated

- **SQL** – Data exploration and aggregation queries
- **Python** – Data cleaning, analysis, and visualization (pandas, matplotlib, seaborn)
- **Excel** – Summary pivot table report (`attrition_summary.xlsx`)

## Files

| File | Description |
|------|-------------|
| `README.md` | Project overview and instructions |
| `analysis.sql` | SQL queries exploring attrition by department, role, satisfaction, etc. |
| `analysis.py` | Python script for EDA, visualizations, and Excel export |
| `attrition_summary.xlsx` | Auto-generated Excel report with pivot-style summary tables |

> **Note:** `attrition_summary.xlsx` is generated by running `analysis.py`.

## Dataset

Download `WA_Fn-UseC_-HR-Employee-Attrition.csv` from Kaggle:
https://www.kaggle.com/datasets/pavansubhasht/ibm-hr-analytics-attrition-dataset

Place the CSV in the project root directory before running.

## Setup & Usage

### 1. Install dependencies

```bash
pip install pandas matplotlib seaborn openpyxl
```

### 2. Load data into SQLite (optional, for SQL exploration)

The SQL file contains queries written for SQLite. You can run them using DB Browser for SQLite or the Python script's built-in SQLite integration.

### 3. Run the Python analysis

```bash
python analysis.py
```

This will:
- Load and clean the CSV data
- Run SQL queries via SQLite in-memory
- Generate charts saved as PNG files
- Export `attrition_summary.xlsx`

## Key Findings

| Driver | Insight |
|--------|---------|
| **Overtime** | Employees who work overtime attrite at ~3x the rate of those who don't |
| **Job Satisfaction** | Low satisfaction (score 1) employees leave at nearly double the rate |
| **Monthly Income** | Employees who leave earn on average ~$2,000 less per month |
| **Years at Company** | Highest attrition in first 1–3 years (onboarding risk window) |
| **Department** | Sales has the highest attrition rate (~21%) |
